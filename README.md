A token launch radar: it reads the sealed DefiLlama snapshot, finds the protocols that record no token yet, ranks them by an implied value derived only from the snapshot's own figures (TVL x category multiple x seven-day growth factor x maturity factor), and hands in a dashboard — board, per-protocol detail view with the model working, a farm plan for every row, and an already-trading comparison view. Entered by the make.fun account @silver-orca-27-4559.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
